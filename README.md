# Sanju AI Voice & Secure Assistant (Android & Web)

একটি স্বয়ংসম্পূর্ণ এআই ভয়েস অ্যাসিস্ট্যান্ট, কলিং ডায়ালার, অফলাইন মোড ও এন্ড-টু-এন্ড এনক্রিপশন সম্বলিত অ্যাপ।

## ফিচারসমূহ:
1. **ভয়েস কলিং ও ডায়ালার**: ব্যাকগ্রাউন্ডে মাইক চালু রেখে "মাকে কল করো" বা নম্বর বলে সরাসরি কল করার সুবিধা।
2. **এআই ভয়েস ও মুড অ্যানালাইসিস**: কথা বলার সাথে সাথে তাৎক্ষণিক উত্তর, সেন্টিমেন্ট ও জরুরী মাত্রা বিশ্লেষণ।
3. **অফলাইন মোড ও সিঙ্ক**: ইন্টারনেট না থাকলেও ১০০% কাজ করে এবং অনলাইনে স্বয়ংক্রিয় ক্লাউড সিঙ্ক হয়।
4. **AES-256 GCM সিকিউর ভল্ট**: মাস্টার পিন দিয়ে গোপন পাসওয়ার্ড ও নোট এনক্রিপশন এবং ব্যাকআপ ফাইল ডাউনলোড/রিস্টোর।
5. **রিয়েল-টাইম নোটিফিকেশন**: ব্রাউজার পুশ ও সাউন্ড এলার্ট।

## কিভাবে Android APK তৈরি করবেন:
1. এই রিপোজিটরি গিটহাবে পুশ করুন।
2. GitHub Actions স্বয়ংক্রিয়ভাবে `.github/workflows/build-apk.yml` রান করে `app-debug.apk` তৈরি করবে।
3. অথবা লোকাল কম্পিউটারে:
   ```bash
   npm install
   npm run build
   npx cap add android
   python3 native-patches/apply_patches.py
   npx cap open android
   ```
